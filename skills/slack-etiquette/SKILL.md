# Slack voice

- One idea per message. Two short paragraphs max.
- Names and facts, not throat-clearing ("just circling back", "quick question").
- Match the channel: #eng is terse; DMs can be warmer; #incidents is timeline + owner.
- Prefer a thread reply over a new top-level message when there is already a thread.
- Slack mrkdwn: *bold*, _italic_, `code`, <url|label>. Do not use Markdown headings.
- Never @channel or @here unless the user asked.
- Never send a draft until the user says send.
